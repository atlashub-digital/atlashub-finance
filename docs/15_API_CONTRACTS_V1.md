# ARO API Contracts V1 — superseded

This early draft described paths and fields that were never released (`checkout_session_id`, `provider` in responses, `/v1/webhooks/<provider>`, entitlement `GET` endpoints, a refund endpoint, routing inspection). It has been removed to avoid contradictions.

Canonical sources:

- API contract: [`openapi/aro-v1.yaml`](../openapi/aro-v1.yaml)
- Developer documentation: [ARO Developer Handbook](./handbook/README.md) — [Checkout Sessions](./handbook/api/checkout-sessions.md), [Orders](./handbook/api/orders.md), [Webhooks](./handbook/api/webhooks.md), [Entitlements](./handbook/api/entitlements.md), [Errors](./handbook/api/errors.md)
- Refunds in V1: [Manual Refund Operations](./handbook/operations/manual-refunds.md) (no refund API)
