## Reprodução

Pré-requisitos: Docker, dependências instaladas dos dois checkouts e tsx do
consumidor. Rodar apenas em ambiente local descartável. Se o store ainda contiver
`JSON.stringify(value)` diretamente, aplicar o patch **no checkout de teste**:

```bash
export ESPELHOMEU_PATH=/srv/atlas/eng/espelhomeu/access-v1
git -C "$ESPELHOMEU_PATH" apply --check "$PWD/docs/implementation/joint-e2e-consumer-store.patch"
git -C "$ESPELHOMEU_PATH" apply "$PWD/docs/implementation/joint-e2e-consumer-store.patch"
docker run --rm -d --name aro-joint-e2e-25 \
  -e POSTGRES_HOST_AUTH_METHOD=trust -p 127.0.0.1::5432 postgres:16-alpine
docker port aro-joint-e2e-25
# Usar a porta efémera informada, não uma DSN existente:
export TEST_DATABASE_URL="postgres://postgres@127.0.0.1:${PG_TEST_PORT}/postgres"
"$ESPELHOMEU_PATH/apps/api/node_modules/.bin/tsx" scripts/e2e/joint-access.mts
# Após execução, inclusive em erro:
docker stop aro-joint-e2e-25
# Remover somente o patch de teste, se não foi incorporado no consumidor:
git -C "$ESPELHOMEU_PATH" apply -R "$PWD/docs/implementation/joint-e2e-consumer-store.patch"
```

`PG_TEST_PORT` deve ser definida com a porta mostrada pelo Docker; aguardar
`docker exec aro-joint-e2e-25 pg_isready -U postgres` antes do runner.
A autenticação trust é exclusiva deste container local/efémero.
O runner valida DSN em 127.0.0.1 e cria sua própria base; nunca apontar para produção.
Duração inclui 120 segundos reais, sem relógio falso ou proof assinada manualmente.
